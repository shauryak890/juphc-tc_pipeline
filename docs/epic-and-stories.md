# Part A — Plan your changes

## Epic
**Modernize Tax Calculator with Containers and DevOps**

Modernize the app by adding unit tests, containerizing it, deploying to IBM Cloud, and automating build/test/deployment using Tekton.

## Stories
1. Run Jasmine tests and record results.
2. Create a Dockerfile.
3. Build the Docker image.
4. Run and test the local container.
5. Push the image to IBM Cloud Container Registry.
6. Deploy the app on IBM Cloud.
7. Create Tekton tasks.
8. Connect the tasks in a Tekton pipeline.
9. Run the pipeline successfully.
10. Deploy and verify the image produced by the pipeline.

Create these in the issue-tracking tool specified by the course and capture screenshots. This markdown file does not create external issues.
